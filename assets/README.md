# Desenhos das dimensões / Measurement drawings

Adicione aqui as duas imagens em PNG com estes nomes **exatos**:

- `dimensoes_medicao_pt.png` — desenho com cotas em português.
- `dimensoes_medicao_en.png` — drawing with English dimension labels.

Na ETAPA 02, o FlangeCheck seleciona automaticamente o arquivo pelo idioma. Enquanto um arquivo não estiver disponível, o aplicativo permanece funcional e mostra uma mensagem discreta no guia visual.

As imagens são **ilustrações esquemáticas** de identificação das cotas `tf`, `D`, `H` e `F`; não representam limites dimensionais ou tolerâncias.
